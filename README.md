# 鉄骨梁 曲げ応力 簡易計算ツール

H形鋼の断面諸元・スパン・等分布荷重から構造計算を行うツール。

## 機能
- H鋼断面 6サイズ選択（H-100×100 〜 H-400×400）
- 最大曲げモーメント M = wL²/8
- 最大せん断力 Q = wL/2
- 最大たわみ δ = 5wL⁴/(384EI)
- E = 205,000 N/mm²固定
- 許容応力(235 N/mm²)・たわみ制限(L/300)との比較
- モーメント図・せん断力図をCanvas描画

## 計算条件
- 単純支持梁（両端ピン支持）
- 等分布荷重
- 弾性係数 E = 205,000 N/mm²（SS400鋼）
